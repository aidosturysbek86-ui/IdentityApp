# IdentityApp - ASP.NET Core Identity жүйесі

Бұл жоба ASP.NET Core Identity арқылы тіркелу, кіру және рөлдік рұқсаттарды (Admin, Student) іске асырады.

## Іске қосу қадамдары
1. Жобаны Visual Studio-да ашыңыз.
2. `appsettings.json` ішіндегі Connection String-ті тексеріңіз.
3. Package Manager Console-да `Update-Database` командасын орындаңыз.
4. Жобаны іске қосыңыз (F5).

## Тестілеу сценарийлері
1. **Тіркелу:** Жаңа пайдаланушы тіркеліп, оған автоматты түрде Student рөлі беріледі.
2. **Кіру:** Тіркелген пайдаланушы email мен құпия сөз арқылы жүйеге кіре алады.
3. **Student рөлінің шектеуі:** Student ретінде кіргенде "Студенттер" бетінде "Жою" батырмасы көрінбейді.
4. **Admin рөлінің рұқсаты:** Admin ретінде кіргенде "Студенттер" бетінде "Жою" батырмасы көрінеді және жою әрекеті орындалады.
5. **Шығу:** Logout POST сұрауы арқылы орындалады.

## Қолданылған технологиялар
*   .NET 10.0
*   ASP.NET Core MVC
*   Entity Framework Core
*   SQL Server (LocalDB)
