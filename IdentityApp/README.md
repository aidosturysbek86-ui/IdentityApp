# IdentityApp - ASP.NET Core Identity жүйесі

Бұл жоба ASP.NET Core Identity арқылы тіркелу, кіру және рөлдік рұқсаттарды (Admin, Student) іске асырады.

## Іске қосу қадамдары
1. Жобаны Visual Studio-да ашыңыз.
2. `appsettings.json` ішіндегі Connection String-ті тексеріңіз.
3. Package Manager Console-да `Update-Database` командасын орындаңыз.
4. Жобаны іске қосыңыз (F5).

## Қолданылған технологиялар
*   .NET 10.0
*   ASP.NET Core MVC
*   Entity Framework Core
*   SQL Server (LocalDB)
